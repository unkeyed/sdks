# DeploymentIssueMeta

Details of the issue. Which fields are set depends on `type`:

- `crash_loop`: `restartCount`, and `reason` and `exitCode` of the last exit
  when one was recorded.


## Example Usage

```typescript
import { DeploymentIssueMeta } from "@unkey/api/models/components";

let value: DeploymentIssueMeta = {
  reason: "out_of_memory",
  exitCode: 137,
  restartCount: 12,
};
```
