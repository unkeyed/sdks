# MatchExpr

A single request match expression. Exactly one of `path`, `method`,
`header`, `queryParam` or `remoteIp` must be set.

## Example Usage

```typescript
import { MatchExpr } from "@unkey/api/models/components";

let value: MatchExpr = {
  path: {
    path: {
      prefix: "/api/",
    },
  },
};
```
